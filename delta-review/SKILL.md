# DELTA 科学结果审阅与阶段门

把技术完成的计算转化为有边界、可反驳、需人工确认的科学判断。永远不把“计算完成”写成“科学问题完成”。

## 输入

要求提供目标科学问题、技术验收通过的批次/任务、冻结输入和正式标签定义、比较基线与单位、适用于该性质的当前正式协议/决策，以及希望判断的下一阶段。若技术证据链未核实，停止科学判断并建议先执行独立的 `$delta-audit`；不要自动串行调用。

默认阅读[科学阶段门框架](references/scientific-stage-gate.md)，但其中通用维度不能代替声子、CTE、热导率或其他性质的正式专属协议。

## 声子专属协议路由

声子/NAC/Phonopy/QHA 的方法正文唯一见[公共谐性声子工作流](../../../docs/工作流/声子工作流.md)，本 Skill 不复制其命令、
收敛、band 或产物清单。审阅时只保留以下边界：

- harmonic 正式量必须来自 Phonopy authoritative workflow；自写程序产物标记为 `derived analysis`/`diagnostic`。
- NAC 适用性、Born/ε∞ 匹配、原始虚频和 band provenance 是审阅前置证据；缺失或不匹配时不得给最终 stability/热学结论。
- q-mesh 收敛不等于 FC2 超胞收敛；diagnostic、evidence status 和 scientific verdict 必须分层。
- harmonic 热学、QHA、CTE 和 phono3py/BTE 不是同一性质；需要哪一项就读取对应正式协议。

## 最小上下文

默认只读根 `AGENTS.md`、目标体系 `04_docs/文档索引.md`、当前科学决策/专属协议、目标批次事实、技术验收摘要、正式结果表和人工报告。每个任务只加载本 Skill，不预读其他 Skill，不递归展开索引。当前证据可闭环时不读 queue/runtime、完整 VASP 输出、无关性质文档、历史审计或经验案例；只有可比性冲突、标签断裂、结论修订或异常解释需要时才追溯。

## 操作顺序

1. 建立两栏证据清单：运行/技术证据只证明输入、执行、收敛和产物可用；正式科学报告、专属协议和科学决策才回答结果意义。拒绝直接从未验收目录抽取科学量。
2. 固定正式标签和结构层级，例如明确能量来自哪个阶段、`TOTEN`/E0/其他量、每 cell/f.u./atom 单位、结构来自哪个 `CONTCAR`。历史/诊断标签不得混入正式排序。
3. 核对可比性：组成、结构来源/表示、赝势、泛函、ENCUT/KPOINTS、磁性/U、阶段协议、收敛、单位和归一化。不可比结果分层报告，不强行合表。
4. 分开审阅能量层级、数值近简并、弛豫结构族/等价性、体积与局域结构、实验一致性、失败/异常和不确定性。能量接近不能替代显式结构匹配。
5. 对枚举/模型结果区分父晶格对称等价、弛豫后盆地汇合和表示 collision。一个层级的发现不能自动改写另一个层级。
6. 评估模型时分开 prospective、retrospective、LOFO/group-aware、full-fit 和无监督 geometry；同时看误差、风险排序、collision、kernel/边界、family 外推和失败案例，不以单一 R²/RMSE 选模。
7. 主动寻找替代解释、反例、覆盖空白和外推边界。0 K DFT 能量不能直接推出有限温自由能、相变温度、声子稳定性、CTE 或热导率；这些性质必须读取各自正式定义、收敛、采样和验收协议。
8. 按框架提出 Go/Conditional Go/No-Go **建议**，列出满足/未满足的门槛和最小下一步。最终科学判断与候选批准必须由用户/研究者确认。
9. 将正式新报告按日期版本写入对应批次 `04_docs/`、体系 `04_docs/科学决策/`/`技术路线/` 或 `03_summary/`；不覆盖旧报告，不修改原始 VASP 结果。

## 经验接口

普通审阅过程中不修改经验、Skill、规范或 AGENTS。仅在异常解释或已知误判复核时查 `docs/经验记录/README.md`，且正式科学决策、当前标签和本批证据始终优先。任务结束时可标记“经验候选”及证据；后续由独立的 `$delta-experience` 任务治理，不得把一次科学结论抽象成普适规则。

## 停止与交接

输入是已技术验收的正式结果和当前科学协议；输出是有边界的科学解释、反证、未决项及需研究者确认的阶段建议。到建议和最小下一步即停止。最终 Go/Conditional Go/No-Go、候选批准和新阶段范围由研究者确认；若确认后需要新的构型设计或生产计算，分别作为新的 `$delta-design` 或 `$delta-vasp` 任务启动，不能由本 Skill 自动继续。

## 禁止事项

- 不把最低有限样本、预测最低或近简并第一名称为全局基态，除非问题定义与证据确实支持。
- 不用报告标题、自动生成 Markdown 或任务 `completed` 代替科学审阅。
- 不把相关性、单个 matched pair、单一 descriptor 或模型系数写成唯一因果机制。
- 不用事后模型表现改写历史 prospective 结论。
- 不自动启动下一阶段、创建候选或修改生产参数。
- 不固化当前 U 编号、候选、最低能结构、阈值或阶段状态。

## 验收与输出

输出至少包含：科学问题与范围、正式标签/单位、可比性表、主要证据与反证、结构族/能量/实验/模型各层结论、外推禁止项、门槛逐项状态、阶段建议、最小下一步和需人工确认的决策。明确区分“技术 Go”“分析步骤 Go”和“科学阶段 Go”。
