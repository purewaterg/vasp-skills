# DELTA 科学阶段门框架

## 决策标签

- **Go**：目标问题在声明范围内已有可比、验收、复现且足够覆盖的证据；关键反例未推翻结论；下一阶段输入和停止条件明确。
- **Conditional Go**：技术结果可用，但覆盖、模型、结构族、实验一致性、协议或机制仍有明确缺口；允许的只是一个有边界的补证步骤，不是默认扩大生产。
- **No-Go**：核心输入/协议不可比、假设被反证、关键验收失败、路线依赖已废止表示，或现有方法无法回答目标问题；先停止并重设问题/输入/方法。

这三类都是给研究者的建议。机器检查可以形成 gate evidence，不能代替最终签字。

## 必审维度

| 维度 | 关键问题 | 常见误判 |
|---|---|---|
| 技术有效性 | 每项任务是否按对应静态/弛豫判据通过？ | 有 OUTCAR/CONTCAR 就成功 |
| 协议可比性 | 标签、组成、结构、赝势、参数、阶段和单位是否一致？ | 混用不同阶段 TOTEN/E0 |
| 构型与结构 | 初始等价、弛豫盆地、最终结构族是否区分？ | 能量近简并即结构等价 |
| 覆盖与反例 | 样本覆盖目标空间吗？关键对照、matched pair 和失败案例够吗？ | 最低有限样本即全局基态 |
| 模型可靠性 | prospective、group-aware、collision、风险排序和外推是否过关？ | 高 R² 或低训练 RMSE 即可生产 |
| 实验与物理 | DFT 结论与可用实验/物理约束一致吗？ | 0 K 排序直接推出有限温性质 |
| 下一步价值 | 补算能否区分竞争解释并改变决策？ | 无目的扩大样本或继续跑分 |

## 推荐报告结构

1. 决策摘要与适用范围
2. 证据截止日期、批次和正式标签
3. 可比性与技术验收
4. 能量、结构族、局域结构和实验一致性
5. 模型/描述符诊断（若适用）
6. 反证、替代解释和未解决问题
7. Gate 逐项结果与 Go/Conditional Go/No-Go 建议
8. 最小下一步、停止条件和人工确认项

## 面向后续性质

Lu/Tm、缺陷、声子、热膨胀和热导率可复用同一证据框架，但每个性质必须定义自己的正式标签、收敛、超胞/采样、有限温或统计方法以及实验比较门槛。当前阳离子构型能量门槛不得直接迁移。
