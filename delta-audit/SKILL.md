# DELTA 阶段与证据审计

把“已登记”“已运行”“技术验收通过”“科学有效”“科学问题完成”分开核验。只报告证据支持的状态，不替项目补造事实。

## 输入

先确定审计对象、截止时间、待回答问题和允许的写入范围。若对象不明确，从根 `项目总目录.md` 定位体系，再从体系 `目录.md` 定位批次；不要按目录名猜状态。仅在来源冲突、历史路线或权威层级不清时阅读[证据路由与判定边界](references/evidence-routing.md)。

## 最小上下文

默认只读根 `AGENTS.md`、目标状态索引、批次 `manifest.yaml` 和 `说明.md`。运行问题再读 `campaign.json`、`进度.md`、runtime/queue 和 acceptance 摘要；科学结论存在性再读体系文档索引与被索引的当前正式报告。当前入口足以回答时，不读 `项目说明.md`、整套规范、脚本正文、历史审计、Skill 架构审计报告、旧报告或大型 VASP 输出。只有出现冲突、缺失、provenance 断点或路线有效性问题时才向历史追溯。

## 操作顺序

1. 从根 `AGENTS.md` 和最窄的项目/体系状态索引定位对象，不从历史审计正文恢复活动路径。
2. 读取批次 `manifest.yaml` 与 `说明.md`，核对身份、上游、状态、科学有效性、来源和输出链接；按问题类型增量读取运行证据或当前正式科学报告，不同时扫描两套证据。
3. 仅在需要结构、参数或路线依据时读取体系 `04_docs/文档索引.md` 指向的当前文档；只在存在专有规则时读取体系 `AGENTS.md`。
4. 将结论分成四层：登记/执行状态、技术验收、科学有效性、阶段决策。任何上一层通过都不自动推出下一层。
5. 核对冻结输入、哈希、索引/坐标约定、结构表示和协议版本。发现冲突、模板残留或来源缺口时标为待人工复核，不自动选择一侧覆盖另一侧。
6. 识别文档时效：现行入口和较新的正式决策决定当前路线；旧报告只证明当时事实。被废止、修复或替代的路线不得复活。
7. 只运行与问题相称的只读检查。优先使用现有 `.delta` 入口；不要读取大型 `OUTCAR`、`vasprun.xml`、`WAVECAR`、`CHGCAR` 或大型数据正文。
8. 输出带证据路径的审计结果、矛盾清单、未证实项、风险和下一步人工动作。若获准写报告，按项目文档分层放置，不修改既有正式科研结果。

## 经验接口

普通审计过程中不修改经验、Skill、规范或 AGENTS。只有遇到异常且当前入口不足时，才从 `docs/经验记录/README.md` 定位相似案例，并用当前正式证据复核。任务结束时可在输出中标记“经验候选”及证据路径；后续由独立的 `$delta-experience` 任务决定是否沉淀、验证、晋升或废止。

## 停止与交接

输入是审计问题和现有证据；输出是分层状态、冲突、缺口和证据路径。到“证据是否存在、是否一致”即停止，不解释能量、结构、声子或热学结果。需要运行操作时交给 `$delta-vasp`；需要科学意义或 Go/Conditional Go/No-Go 建议时，把正式报告与技术验收证据交给 `$delta-review`。不得自动调用下一个 Skill 或替用户跨过人工门。

## 确定性检查

- 批次/索引一致性：`python3 .delta/scripts/update_indexes.py --check`
- Markdown 变更后：`python3 .delta/scripts/check_markdown_links.py --check`
- 根目录与缓存卫生：`python3 .delta/scripts/check_root_hygiene.py --check`
- 明确候选任务的生命周期：仅用 `.delta/scripts/vasp_task_lifecycle.py` 做只读审计；其结论不是删除许可。

先确认参数与目标路径，再执行检查。不要把检查器返回 0 解释为科学结论成立。

## 禁止事项

- 不启动或续算 VASP，不修改输入/输出，不删除、迁移或重命名历史证据。
- 不由 slug、目录时间、`OUTCAR` 存在、PID 消失或报告标题推断完成。
- 不把 `prepared`、部分完成或诊断批次包装成 `completed`。
- 不把历史审计中的旧路径、旧参数、旧调度方式或已修复候选表当作现行入口。
- 不为消除矛盾静默改写 manifest、说明或正式报告。

## 验收与输出

审计输出至少包含：范围与截止时间、读取的权威来源、四层状态表、冻结输入检查、冲突与缺口、废止路线检查、安全边界、可复现命令和人工复核项。每个关键结论必须能回溯到具体文件；无法证明时明确写“未证实”。
